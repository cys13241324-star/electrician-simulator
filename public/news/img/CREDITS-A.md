## 페이지별 작업 요약

- **news-airbnb**: 숙소 리스팅 카드의 만화풍 집 SVG(`houseSvg`) → 실내 사진 3종으로 교체. 인스타식 카드 프레임/배지/위시버튼/도트 UI 보존.
- **news-auction**: 경매 출품작 SVG 라이브러리(전구·필사본·코일·회로·변압기·라디오·모터) → 실사진. `portrait`(회화) 항목은 명화풍 일러스트라 보존.
- **news-awards-ceremony**: 시상식 무대 히어로 SVG 뒤에 실사진 배경 + 스크림, 무대 SVG는 screen 블렌드로 금색 타이포/트로피 유지.
- **news-camping**: 히어로 풍경 일러스트 SVG → 캠핑 야경 실사진. 캡션/네비 보존, SVG는 `<template>`로 비표시 보존.
- **news-detective**: 메인 폴라로이드 "사건 현장" 배전반 SVG → 전기 계량기 실사진(폴라로이드 프레임·세피아 필터 그대로). 용의자 폴라로이드(옴/키르히호프/패러데이 등 인물 일러스트)는 캐릭터 디자인이라 보존.
- **news-documentary**: 히어로 배경 SVG → 다큐 카메라 실사진. hero-grad/타이틀 그대로. 에피소드 썸네일·출연자 아바타는 토픽 식별용 디자인 아이콘이라 보존.
- **news-escape-room**: 히어로 어두운 방 배경 SVG → 어두운 폐공간 실사진 + 라디얼 스크림. 타이틀/LIVE 칩 보존.
- **news-food-delivery**: 식당·메뉴·장바구니 썸네일의 SVG 심볼(`<use>`) → 음식 종류별 실사진 9종(라멘/피자/버거/도시락/파스타/카레/케이크/한식/양식)으로 매핑. 배지·찜 버튼 등 UI 보존.
- **news-game-pass**: 메인 히어로 키아트 SVG(게임 스크린샷 목업) → 네온 아케이드 실사진 + 스크림. 좌측 텍스트/버튼, NEXT UP 패널 보존. 개별 게임 커버 일러스트(`cover()`)는 장르 식별용 디자인이라 보존.

## 스킵한 페이지 (사유)

- **news-ai-chat / news-discord**: 채팅 앱 UI 자체가 디자인. 아바타는 이니셜 원형(의도된 UI), 실사진 자리 없음.
- **news-arcade / news-game**: 픽셀아트 게임 화면·캐릭터 아트가 테마 디자인.
- **news-astrology / news-fortune / news-dna-test**: 별자리 차트·타로·DNA 헬릭스 등 그래픽이 콘텐츠 디자인 자체.
- **news-blog**: 텍스트 회고록 + 교육용 회로도 SVG(정보성 도해). 사진 자리 없음.
- **news-boarding-pass / news-call-center**: 탑승권·콜센터 UI 디자인. 실사진 자리 없음.
- **news-cafe-menu / news-catalog / news-flyer**: 라인아트 메뉴판·카탈로그·전단 일러스트가 의도된 디자인 미학.
- **news-car-dashboard**: 계기판 게이지 = 의도된 인스트루먼트 클러스터 디자인.
- **news-comic**: 만화 패널 아트가 테마 디자인 자체.
- **news-course**: 기존 파이프라인이 이미 `course.jpg`로 photo-role 적용 완료(구매 카드 썸네일). 추가 작업 불필요 — 내 담당 파일 외 신규 변경 없음.
- **news-debate**: 토론 무대 SVG에 LIVE 표시·반응 점등 등 동적/인터랙티브 요소 포함. 정적 사진 교체 시 시뮬레이션 깨질 위험 → 보존.
- **news-department-store**: 이벤트 슬라이드의 추상 기하 "포스터"는 액센트 컬러 연동 장식. 진짜 사진 자리 아님(에디토리얼 디자인).
- **news-detective(용의자)**: 옴·키르히호프 등 명명된 역사 인물 일러스트 → 무작위 인물 사진은 부적합, 보존.
