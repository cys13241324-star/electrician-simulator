PLC 래더 다이어그램 시뮬레이터

자기유지(Self-holding) 회로는 PB1을 잠깐 눌러도 출력이 유지되고 PB2(정지)로만 해제됩니다. 인터록(Interlock) 은 정·역 운전 코일이 동시에 ON 되는 것을 b접점으로 금지해 사고를 막습니다. 타이머(TIM) 는 입력 ON 후 설정 시간 경과 시 출력합니다.

입력 X0 (PB1·기동)

OFF

입력 X1 (PB2·정지)

OFF

출력 Y0 (정회전 M1)

OFF

출력 Y1 (역회전 M2)

OFF

① 입력 리프레시

PB · 센서 신호를 X0~Xn 이미지 메모리에 저장

② 프로그램 스캔

래더를 위→아래·좌→우로 연산

③ 출력 리프레시

연산 결과 Y0~Yn 을 실 출력으로 갱신

④ 시스템 처리

자기진단·통신·타이머 갱신 후 반복

📐 불 대수 (Boolean Logic)

$$\text{자기유지: } Y_0 = (X_0 + Y_0) \cdot \overline{X_1}$$
$$\text{인터록: } Y_0 = (X_0 + Y_0)\cdot \overline{X_1}\cdot \overline{Y_1}$$
$$\qquad\quad Y_1 = (X_2 + Y_1)\cdot \overline{X_1}\cdot \overline{Y_0}$$
$$\text{타이머: } T_0 = X_0,\ \ Y_0 = T_0(\text{현재값} \ge \text{설정값})$$

자기유지 — 출력 자신의 a접점을 기동 접점과 병렬로 연결해 ON을 기억합니다. 인터록 — 상대 출력의 b접점(─|/|─)을 직렬로 추가해 동시 ON을 물리적으로 금지합니다. 타이머 — TON(On-delay)은 코일이 ON된 후 설정값에 도달하면 접점이 ON 됩니다.
