🏘 마이크로그리드 (Microgrid) 시뮬레이터

대기 동기화 자립 복귀 연계

계통연계 시 그리드가 주파수·전압을 결정 → 60Hz 일정. 자립 시 ESS·디젤이 VSG(Virtual Synchronous Generator) · P-f Droop 제어로 주파수 유지 → 부하 변동 시 ±0.3Hz 진동.

📐 마이크로그리드 핵심 공식

전력 균형 (Power Balance)

\(P_{pv}+P_{w}+P_{ess}+P_{dg}+P_{grid}=P_{load}\)

P-f Droop 제어

\(f = f_{0} - k_{p}\,(P - P_{0})\)

자급률 (Self-Sufficiency)

\(SSR = \dfrac{P_{pv}+P_{w}+P_{ess,d}+P_{dg}}{P_{load}}\times 100\) [%]
  • PCC 공통연계점 · 마이크로그리드 ↔ 상위 계통 경계, 차단기 CB로 분리
  • ISL 단독운전 검출 → 정전 시 0.5초 내 자립모드 전환 (IEEE 1547 / KS C IEC 62116)
  • VSG 가상관성 (Virtual Synchronous Generator) — 인버터가 회전기 관성을 모방, 주파수 안정도 ↑
  • Droop P-f / Q-V 드룹 제어 → 다중 인버터 부하 분담 (Master 없이 병렬 운전)
  • 대기 → 동기화 · 그리드 전압/위상 일치 (Δθ < 10°, ΔV < 5%, Δf < 0.2Hz) 후 CB 투입
  • 자립 → 복귀 · 그리드 복구 감지 → 재동기화 → Soft-Closing → 계통연계 복귀
