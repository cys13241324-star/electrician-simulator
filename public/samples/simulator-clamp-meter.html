🧲 클램프미터 (CT) 시뮬레이터

📐 클램프미터 핵심 공식

CT 변류비

\(\dfrac{I_2}{I_1} = \dfrac{N_1}{N_2}\)

암페어 법칙

\(\oint \vec{B}\cdot d\vec{l} = \mu_0 I_{enc}\)

유도 기전력

\(e = -N\dfrac{d\Phi}{dt}\)
  • AC 클램프 · 자속 변화 → 2차 코일 유도 기전력 사용
  • DC 클램프 · 홀 효과(Hall) 센서로 정자속 측정
  • 3상 일괄 클램프 · 벡터합 ≈ 0 → 누전 검출용 ZCT 원리
  • 중요 · 도선이 클램프 중심에서 벗어날수록 자속 분포가 비대칭 → 측정 오차 증가

학습 포인트

왕복 2선을 함께 둘러싸면 벡터합 ≈ 0 → 측정값이 거의 0 (누전 시에만 0이 아님)

엇갈림/기울임은 자속 분포 비대칭 → 오차 ↑ (일반 클램프 ±2~5% 등급)

DC 측정은 자속 변화가 없어 일반 CT 불가 → 홀 센서 사용
