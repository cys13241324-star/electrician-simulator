🧭 임피던스 벡터 시뮬레이터

복소 평면에서 R(실수축)과 X = X_L − X_C(허수축)을 합성하여 임피던스 Z = R + jX를 시각화. 위상각 θ로 회로의 성격을 판별.

R 실수축 벡터 X_L 유도성 (+j) X_C 용량성 (−j) Z 합성 벡터 θ 위상각 호

📐 복소 임피던스 핵심 공식

복소 임피던스

\(Z = R + j(X_L - X_C)\)

크기

\(|Z| = \sqrt{R^2 + X^2}\)

위상각

\(\theta = \tan^{-1}\!\dfrac{X}{R}\)

유도 리액턴스

\(X_L = \omega L = 2\pi f L\)

용량 리액턴스

\(X_C = \dfrac{1}{\omega C} = \dfrac{1}{2\pi f C}\)

공진 조건

\(X_L = X_C \;\Rightarrow\; \theta = 0\)
  • X > 0 · 유도성 (X_L > X_C) — 전류가 전압보다 뒤짐 (지상)
  • X < 0 · 용량성 (X_L < X_C) — 전류가 전압보다 앞섬 (진상)
  • X = 0 · 공진 — 순저항, |Z| 최소, 동상

학습 포인트

실수축: 저항 R — 에너지 소비, 위상 변화 없음

+j 허수축: 코일 X_L — 자기에너지 저장

−j 허수축: 콘덴서 X_C — 전기에너지 저장
