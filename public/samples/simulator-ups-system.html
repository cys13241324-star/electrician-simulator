전환시간 (Transfer Time)

Online: 0 ms · Line-int: 2~6 ms · Standby: 6~10 ms
  • Online 더블 컨버전 · 그리드 → 정류기 → DC링크 → 인버터 → 부하 · 상시 인버터 출력 · 전환 0 ms
  • Line-int 라인-인터랙티브 · AVR로 전압 안정화 · 정전 시 인버터 전환 · 2~6 ms
  • Standby 오프라인 · 평소엔 그리드 직결 · 정전 시 인버터 ON · 6~10 ms
  • SOC 배터리 잔존용량 · 백업 시간 ∝ SOC · 부하 작을수록 ↑
  • 정류기 (Rectifier) AC 입력을 DC로 변환 · 동시에 배터리 충전
  • 인버터 (Inverter) DC링크의 DC를 정현파 AC로 출력 (PWM)
