접지 방식 (TT / TN / IT) 시뮬레이터

TT

TN-S

TN-C

N과 PE를 PEN으로 통합 (4선식)

TN-C-S

전원~인입 PEN, 인입 이후 N·PE 분리

한국 산업/상업 표준 · 경제성 + 안전성 절충

IT

전원 측 비접지(또는 고저항접지) · 부하 측 접지

1차 지락 시 회로 유지 → 무정전 필요 환경 · 병원 수술실 · 화학 플랜트 · 절연감시장치(IMD) 필수

📐 고장 루프 임피던스 · 접촉 전압

$$I_f = \frac{V_0}{Z_s}, \qquad U_T = I_f \cdot R_A \le 50\,\text{V (AC, 상시)}$$
$$\text{TT: } Z_s = R_B + R_A \quad\Rightarrow\quad I_f \approx \frac{V_0}{R_B + R_A} \ \text{(수 A — RCD 차단)}$$
$$\text{TN: } Z_s = Z_L + Z_{PE} \ \text{(저임피던스)} \quad\Rightarrow\quad I_f \gg I_n \ \text{(MCB 즉시 차단)}$$

TT는 대지 저항이 경로에 끼어 I_f가 작으므로 RCD(누전차단)가 필수. TN은 금속 도체 경로로 I_f가 크므로 과전류 차단(MCB)만으로 동작 가능. IT는 1차 지락이 폐회로를 이루지 않아 차단 없이 운전 지속, 단 2차 지락은 단락이므로 위험.
